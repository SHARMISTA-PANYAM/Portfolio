# Sharmista Panyam Portfolio

GitHub Pages-ready portfolio.

## Files
- `index.html`
- `style.css`
- `script.js`
- `assets/Sharmista_Panyam_DevOpsEngineer.docx`

## Publish on GitHub Pages
1. Upload these files to the root of your portfolio repository.
2. Commit and push.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your main branch and `/ (root)`.
6. Save.

The site uses Google Fonts, Devicon, and Simple Icons via public CDNs.
